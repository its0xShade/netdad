# UDP — ساختار و عملکرد

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- ساختار UDP Datagram را توضیح دهد
- ویژگی‌های UDP را بیان کند
- کاربردهای مناسب UDP را نام ببرد

---

## ۱. UDP چیست؟

**User Datagram Protocol** پروتکلی **سبک، سریع و بدون اتصال** است. هیچ تضمینی برای تحویل، ترتیب یا عدم تکرار ندارد.

---

## ۲. ساختار UDP Header

ساده‌تر از TCP — فقط ۸ بایت:

| فیلد | اندازه | توضیح |
|---|---|---|
| Source Port | ۱۶ بیت | شماره پورت مبدأ |
| Destination Port | ۱۶ بیت | شماره پورت مقصد |
| Length | ۱۶ بیت | طول Datagram |
| Checksum | ۱۶ بیت | بررسی صحت (اختیاری) |

---

## ۳. UDP vs. TCP

| ویژگی | TCP | UDP |
|---|---|---|
| اتصال | Connection-Oriented | Connectionless |
| تضمین | بله | خیر |
| ترتیب | حفظ می‌شود | تضمین نمی‌شود |
| سرعت | کمتر | بیشتر |
| سربار Header | ۲۰ بایت | ۸ بایت |

---

## ۴. کاربردهای UDP

| کاربرد | چرا UDP؟ |
|---|---|
| **DNS** | درخواست کوتاه، پاسخ سریع لازم است |
| **VoIP (تماس تلفنی)** | تأخیر کمتر مهم‌تر از تحویل کامل است |
| **بازی آنلاین** | تأخیر = مرگ؛ بسته گم شده بهتر از تأخیر زیاد |
| **ویدیوی استریم** | چند فریم گم شدن قابل قبول است |
| **DHCP** | درخواست اولیه ساده |

---

## ۵. مثال

```
Client                          Server (DNS)
   |                               |
   |  --- UDP Query (port 53) ---→ |  بدون Handshake
   |                               |
   |  ←-- UDP Response ------------ |  پاسخ سریع
   |                               |
```

هیچ اتصالی برقرار نمی‌شود — فقط درخواست و پاسخ.
