# مقایسه TCP و UDP

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- بر اساس نیاز، پروتکل مناسب (TCP یا UDP) را انتخاب کند
- سناریوهای واقعی را تحلیل کند

---

## ۱. جدول مقایسه نهایی

| ویژگی | TCP | UDP |
|---|---|---|
| اتصال | Yes | No |
| تضمین تحویل | Yes | No |
| ترتیب | Yes | No |
| سرعت | پایین‌تر | بالاتر |
| سربار | زیاد (۲۰B header) | کم (۸B header) |
| کنترل جریان | Yes | No |
| کنترل ازدحام | Yes | No |
| کاربرد | فایل، وب، ایمیل | DNS، VoIP، بازی، استریم |

---

## ۲. قاعده تصمیم‌گیری

```
آیا تحویل کامل و ترتیب مهم است؟
  ├─ بله → TCP
  └─ خیر → آیا تأخیر مهم‌تر است؟
              ├─ بله → UDP
              └─ خیر → هر دو قابل استفاده است
```

---

## ۳. کاربردها

**TCP:** HTTP(S)، FTP، SMTP، SSH، Telnet، POP3، IMAP

**UDP:** DNS، DHCP، SNMP، VoIP، RTP، بازی آنلاین، استریم ویدیو

---

## ❓ سوالات مرور

1. تماس تصویری کدام پروتکل را ترجیح می‌دهد؟ چرا؟
2. ارسال ایمیل چرا TCP استفاده می‌کند؟
3. DNS چرا هر دو را پشتیبانی می‌کند؟
