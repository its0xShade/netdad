# سناریوهای عملی عیب‌یابی

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- مشکلات رایج شبکه را تحلیل کند
- برای هر سناریو راه‌حل پیشنهاد دهد

---

## سناریو ۱: "اینترنت ندارم"

```
مرحله ۱: ipconfig → آدرس IP وجود دارد؟
  ├── خیر → DHCP مشکل دارد. Cable بررسی کنید.
  └── بله → مرحله ۲
مرحله ۲: ping 192.168.1.1 (Gateway)
  ├── ناموفق → مشکل لایه ۲. کابل، Switch
  └── موفق → مرحله ۳
مرحله ۳: ping 8.8.8.8
  ├── ناموفق → مشکل در ISP یا روتر
  └── موفق → مرحله ۴
مرحله ۴: nslookup google.com
  ├── ناموفق → DNS مشکل دارد → DNS را عوض کنید
  └── موفق → مرحله ۵
مرحله ۵: بررسی فایروال/آنتی‌ویروس
```

---

## سناریو ۲: "سایت‌ها کند باز می‌شوند"

```
ping google.com → Latency بررسی شود
pathping → تأخیر در کدام hop است؟
بررسی: ازدحام؟ پهنای باند؟ DNS کند؟
```

---

## سناریو ۳: "به یک دستگاه در شبکه دسترسی ندارم"

```
ping دستگاه → ناموفق
آدرس IP و Subnet بررسی شود
Firewall دستگاه مقصد بررسی شود
```

---

## ❓ سوالات مرور

1. اگر ipconfig آدرس APIPA نشان دهد، مشکل چیست؟
2. اگر ping به Gateway موفق ولی ping به 8.8.8.8 ناموفق باشد؟
3. اگر nslookup کار نکند ولی ping به IP کار کند؟
