# مدل OSI — Open Systems Interconnection

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- هفت لایه مدل OSI را نام ببرد و وظیفه هرکدام را توضیح دهد
- مفهوم لایه‌بندی (Layering) در شبکه را درک کند
- مثال واقعی برای هر لایه ارائه دهد
- تفاوت لایه‌های بالا و پایین را بیان کند

> **پیش‌نیاز:** [درس ۰۱ — شبکه کامپیوتری چیست؟](../01-network-fundamentals/01-what-is-a-network.md) و [درس ۰۲ — دستگاه‌های شبکه](../01-network-fundamentals/02-network-devices.md)

---

## ۱. مقدمه

ارتباط در شبکه بسیار پیچیده است. اگر بخواهیم تمام این پیچیدگی را به‌صورت یک تکه واحد ببینیم، درک آن تقریباً غیرممکن است.

بنابراین مهندسان شبکه یک راه حل هوشمندانه پیشنهاد دادند: **تقسیم مشکل به بخش‌های کوچک‌تر و مستقل**. هر بخش یک **لایه** (Layer) نامیده می‌شود و وظیفه مشخصی دارد.

این مدل لایه‌بندی شده، **OSI Model** نام دارد.

---

## ۲. مدل OSI چیست؟

**OSI (Open Systems Interconnection)** مدلی مفهومی است که توسط سازمان **ISO** (سازمان بین‌المللی استانداردها) در سال ۱۹۸۴ طراحی شد.

این مدل ارتباط شبکه را به **۷ لایه** تقسیم می‌کند. هر لایه یک وظیفه مشخص دارد و با لایه‌های بالا و پایین خود ارتباط برقرار می‌کند.

> **نکته مهم:** OSI یک مدل **مفهومی** است، نه یک پروتکل واقعی. از آن برای **آموزش و تحلیل** استفاده می‌شود.

---

## ۳. هفت لایه OSI

از پایین به بالا:

```text
┌─────────────────────────┐
│   7. Application        │  ← لایه برنامه
├─────────────────────────┤
│   6. Presentation       │  ← لایه ارائه
├─────────────────────────┤
│   5. Session            │  ← لایه نشست
├─────────────────────────┤
│   4. Transport          │  ← لایه انتقال
├─────────────────────────┤
│   3. Network            │  ← لایه شبکه
├─────────────────────────┤
│   2. Data Link          │  ← لایه پیوند داده
├─────────────────────────┤
│   1. Physical           │  ← لایه فیزیکی
└─────────────────────────┘
```

---

## ۴. توضیح هر لایه

### لایه ۱ — Physical (فیزیکی)

**وظیفه:** انتقال بیت‌های خام (۰ و ۱) روی رسانه فیزیکی.

این لایه به هیچ معنایی در داده‌ها کاری ندارد. فقط بیت‌ها را از نقطه‌ای به نقطه دیگر حرکت می‌دهد.

| مثال | توضیح |
|---|---|
| کابل Ethernet (UTP) | سیم‌های مسی انتقال داده |
| فیبر نوری | انتقال با نور |
| امواج رادیویی | Wi-Fi، بلوتوث |
| سیگنال‌های الکتریکی | ولتاژ بالا/پایین = ۱/۰ |

**دستگاه مرتبط:** Hub، کابل، کانکتور، سیگنال

---

### لایه ۲ — Data Link (پیوند داده)

**وظیفه:** انتقال **Frame** بین دو دستگاه همسایه روی یک لینک مستقیم.

این لایه دو زیرلایه دارد:

- **MAC (Media Access Control)** — آدرس‌دهی فیزیکی و کنترل دسترسی
- **LLC (Logical Link Control)** — هماهنگی بین لایه فیزیکی و شبکه

| مثال | توضیح |
|---|---|
| آدرس MAC | آدرس سخت‌افزاری یکتای کارت شبکه |
| Ethernet Frame | قالب داده در این لایه |
| Switch | دستگاهی که در این لایه کار می‌کند |
| VLAN | تقسیم منطقی شبکه |

---

### لایه ۳ — Network (شبکه)

**وظیفه:** آدرس‌دهی و مسیریابی **بسته‌ها** (Packets) بین شبکه‌های مختلف.

این لایه تصمیم می‌گیرد بسته از چه مسیری به مقصد برسد.

| مثال | توضیح |
|---|---|
| آدرس IP | شناسه یکتای دستگاه در شبکه |
| Router | مسیریابی بین شبکه‌ها |
| ICMP | پروتکل عیب‌یابی (ping) |
| ARP | تبدیل IP به MAC |

---

### لایه ۴ — Transport (انتقال)

**وظیفه:** انتقال **قابل‌اعتماد** داده بین دو برنامه روی دستگاه‌های مختلف.

این لایه مسئول تقسیم داده به قطعات کوچک‌تر، ترتیب‌دهی، و بازیابی داده‌های از‌دست‌رفته است.

| مثال | توضیح |
|---|---|
| TCP | انتقال قابل‌اعتماد با اتصال مستقر |
| UDP | انتقال سریع بدون اتصال |
| شماره پورت | شناسایی برنامه مقصد |
| Three-Way Handshake | برقراری اتصال TCP |

---

### لایه ۵ — Session (نشست)

**وظیفه:** مدیریت **نشست‌ها** (Sessions) — ایجاد، نگهداری و خاتمه ارتباط بین دو برنامه.

| مثال | توضیح |
|---|---|
| NetBIOS | نام‌گذاری و ارتباط در شبکه محلی |
| RPC (Remote Procedure Call) | فراخوانی تابع از راه دور |
| احراز هویت | بررسی هویت در ابتدای نشست |

---

### لایه ۶ — Presentation (ارائه)

**وظیفه:** **ترجمه، رمزنگاری و فشرده‌سازی** داده‌ها.

این لایه مطمئن می‌شود داده‌ای که یک برنامه ارسال می‌کند، برای برنامه مقصد قابل فهم باشد.

| مثال | توضیح |
|---|---|
| SSL/TLS | رمزنگاری ارتباطات |
| JPEG، PNG | قالب‌های تصویر |
| ASCII، UTF-8 | کدگذاری متن |
| فشرده‌سازی ZIP | کاهش حجم داده |

---

### لایه ۷ — Application (برنامه)

**وظیفه:** ارائه **رابط کاربری و سرویس‌های شبکه** به برنامه‌های کاربردی.

این لایه مستقیماً با برنامه‌ای که کاربر استفاده می‌کند (Browser، Email Client و ...) ارتباط دارد.

| مثال | توضیح |
|---|---|
| HTTP/HTTPS | انتقال صفحات وب |
| DNS | تبدیل نام دامنه به IP |
| SMTP/POP3/IMAP | ارسال و دریافت ایمیل |
| FTP | انتقال فایل |
| SSH | اتصال امن از راه دور |

---

## ۵. یادآوری حروفی

برای به‌خاطر سپردن ترتیب لایه‌ها از پایین به بالا، عبارت زیر کمک می‌کند:

> **P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way

| حرف | لایه |
|---|---|
| P | Physical |
| D | Data Link |
| N | Network |
| T | Transport |
| S | Session |
| P | Presentation |
| A | Application |

---

## ۶. مثال واقعی: سفر یک پیام از طریق لایه‌ها

فرض کنید در Browser آدرس example.com را تایپ می‌کنید. بیایید ببینیم یک درخواست HTTP از چه لایه‌هایی عبور می‌کند:

```text
مرحله ارسال (از بالا به پایین):

Application  ← درخواست HTTP ایجاد می‌شود
    ↓
Presentation ← رمزنگاری (HTTPS = TLS)
    ↓
Session      ← نشست TLS برقرار می‌شود
    ↓
Transport    ← داده به Segment تقسیم می‌شود (TCP + پورت ۴۴۳)
    ↓
Network      ← آدرس IP مقصد اضافه می‌شود → Packet
    ↓
Data Link    ← آدرس MAC اضافه می‌شود → Frame
    ↓
Physical     ← Frame به سیگنال الکتریکی/نوری تبدیل می‌شود
```

و وقتی پاسخ از سرور برمی‌گردد، عکس این فرآیند اتفاق می‌افتد (از پایین به بالا).

---

## ۷. نکات مهم

1. **هر لایه فقط با لایه مجاور خود ارتباط دارد.** لایه ۷ نمی‌داند لایه ۱ چیست.

2. **در هر لایه، به داده یک Header اضافه می‌شود.** این فرآیند **Encapsulation** نام دارد (درس بعدی).

3. **دستگاه‌ها در لایه‌های مختلفی کار می‌کنند:**
   - Hub → لایه ۱
   - Switch → لایه ۲
   - Router → لایه ۳
   - Firewall → لایه ۳ تا ۷

4. **این مدل فقط یک چارچوب نظری است.** در عمل، از مدل TCP/IP استفاده می‌شود (درس بعدی).

---

## ⚠️ خطاهای رایج

1. **گیج شدن لایه‌ها:** به‌یاد داشته باشید لایه ۱ پایین‌ترین و لایه ۷ بالاترین است.

2. **فکر کردن که OSI خودش یک پروتکل است:** OSI فقط یک **مدل مفهومی** برای توضیح و آموزش است.

3. **ادغام Network و Transport:** لایه Network آدرس‌دهی و مسیریابی انجام می‌دهد. لایه Transport انتقال قابل‌اعتماد را تضمین می‌کند.

---

## ❓ سوالات مرور

1. هفت لایه مدل OSI را از پایین به بالا نام ببرید.
2. لایه Data Link چه وظیفه‌ای دارد؟
3. در کدام لایه آدرس IP استفاده می‌شود؟
4. Switch در کدام لایه OSI کار می‌کند؟
5. فرآیند Encapsulation چیست؟ (به‌صورت خلاصه)
6. چرا مدل OSI به ۷ لایه تقسیم شده است؟
