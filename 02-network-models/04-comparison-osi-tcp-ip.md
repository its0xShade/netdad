# مقایسه نهایی OSI و TCP/IP

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- OSI و TCP/IP را در یک جدول مقایسه کند
- تشخیص دهد در هر موقعیت از کدام مدل استفاده می‌شود
- لایه‌های معادل بین دو مدل را نشان دهد
- دلایل استفاده از هر مدل را بیان کند

## ۱. جدول مقایسه کامل

| معیار | OSI | TCP/IP |
|---|---|---|
| تعداد لایه‌ها | ۷ | ۴ (یا ۵) |
| سازنده | ISO | DARPA (وزارت دفاع آمریکا) |
| سال ارائه | ۱۹۸۴ | ۱۹۷۰s |
| نوع | مفهومی / آموزشی | عملی / کاربردی |
| استفاده در | آموزش، عیب‌یابی | اینترنت واقعی |
| رویکرد | در ابتدا پروتکل طراحی کرد، بعد مدل | ابتدا پروتکل‌ها توسعه یافتند، بعد مدل |
| انعطاف | کمتر (تعریف دقیق) | بیشتر (پروتکل‌ها مستقل) |

## ۳. کی از کدام مدل استفاده کنیم؟

### از OSI استفاده کنید وقتی:
- در حال **آموزش** مفاهیم شبکه هستید
- می‌خواهید یک **مشکل** را تحلیل کنید (در کدام لایه مشکل است؟)
- با **فروشنده‌ها و استانداردها** کار می‌کنید
- می‌خواهید یک **طراحی شبکه** را مستند کنید

### از TCP/IP استفاده کنید وقتی:
- با **پروتکل‌های واقعی** اینترنت کار می‌کنید
- **پیکربندی شبکه** انجام می‌دهید
- **برنامه‌نویسی شبکه** می‌کنید (Socket Programming)
- **عیب‌یابی** عملی انجام می‌دهید

---

## ۴. چرا هر دو مهم هستند؟

**OSI** مثل یک نقشه جامع است — کمک می‌کند بدانید هر چیزی کجاست.
**TCP/IP** مثل جاده‌های واقعی است — با آن واقعاً حرکت می‌کنید.

> **به یاد داشته باشید:** در مصاحبه‌های شغلی و امتحانات، هر دو مدل پرسیده می‌شوند. OSI برای درک تئوری و TCP/IP برای کار عملی ضروری است.

---

## ۵. مثال نهایی: وب‌گردی

وقتی در Browser آدرس google.com را تایپ می‌کنید:

| مرحله | OSI می‌گوید | TCP/IP می‌گوید |
|---|---|---|
| درخواست DNS | Application Layer | Application Layer |
| UDP برای DNS | Transport Layer | Transport Layer |
| IP برای مسیریابی | Network Layer | Internet Layer |
| Ethernet برای ارسال | Data Link Layer | Network Access Layer |
| سیگنال روی کابل | Physical Layer | Network Access Layer |

## ❓ سوالات مرور

1. OSI چند لایه دارد؟ TCP/IP چند لایه؟
2. کدام لایه OSI در TCP/IP وجود ندارد؟
3. چرا TCP/IP عملی‌تر از OSI است؟
4. لایه Session در TCP/IP کجایی است؟
5. کی باید از OSI و کی از TCP/IP استفاده کرد؟
