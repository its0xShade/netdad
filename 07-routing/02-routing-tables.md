# جداول مسیریابی — Routing Tables

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- جدول مسیریابی را توضیح دهد
- مفهوم Default Route را بیان کند
- فرآیند جستجو در جدول را شرح دهد

---

> **پیش‌نیاز:** [مسیریابی چیست؟](01-introduction-to-routing.md)

---

## ۱. جدول مسیریابی چیست؟

هر روتر یک **جدول مسیریابی** (Routing Table) دارد که لیست مسیرهای موجود را ذخیره می‌کند.

### مثال:

```
Destination       Subnet Mask       Next Hop         Interface
192.168.1.0       255.255.255.0     Direct           eth0
192.168.2.0       255.255.255.0     Direct           eth1
10.0.0.0          255.0.0.0         192.168.1.1      eth0
0.0.0.0           0.0.0.0           85.214.132.1     eth0
```

---

## ۲. فرآیند جستجو

وقتی بسته‌ای به روتر می‌رسد:

1. آدرس IP مقصد را با **Longest Prefix Match** مقایسه کنید
2. مسیری با دقیق‌ترین (طولانی‌ترین) پیشوند پیدا کنید
3. بسته را به Next Hop یا Interface مربوطه ارسال کنید

**مثال:** آدرس مقصد 192.168.1.50 → Longest Match = 192.168.1.0/24 → Interface eth0

---

## ۳. انواع مسیرها

| نوع | توضیح |
|---|---|
| **Directly Connected** | شبکه مستقیماً به رابط متصل |
| **Static** | توسط مدیر دستی تعریف شده |
| **Dynamic** | توسط پروتکل مسیریابی یاد گرفته شده |
| **Default (0.0.0.0/0)** | مسیر پیش‌فرض — اگر مسیر دیگری پیدا نشد |

---

## ۴. مشاهده جدول مسیریابی

**Windows:** `route print` یا `netstat -r`
**Linux:** `ip route` یا `route -n`

---

## ۵. Longest Prefix Match

اگر چند مسیر با آدرس مقصد سازگار باشند، **دقیق‌ترین** (طولانی‌ترین Subnet Mask) انتخاب می‌شود:

```
مسیر ۱: 192.168.0.0/16    (16 بیت)
مسیر ۲: 192.168.1.0/24    (24 بیت) ← برنده!
مسیر ۳: 192.168.1.128/25  (25 بیت) ← دقیق‌تر!
```

---

## ❓ سوالات مرور

1. جدول مسیریابی چه اطلاعاتی ذخیره می‌کند؟
2. Longest Prefix Match چیست؟
3. Default Route چه زمانی استفاده می‌شود؟
4. چگونه جدول مسیریابی را در لینوکس ببینیم؟
