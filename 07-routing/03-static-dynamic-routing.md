## ۱. مسیریابی استاتیک (Static Routing)

مسیرها **توسط مدیر شبکه به‌صورت دستی** در روتر تعریف می‌شوند.

**مثال در لینوکس:**
```bash
ip route add 10.0.0.0/8 via 192.168.1.1
```

**مزایا:**
- کنترل کامل
- بدون ترافیک اضافی
- امنیت بیشتر

**معایب:**
- مدیریت دستی (تغییر = کار دستی)
- مقیاس‌پذیری ضعیف
- عدم انعطاف (تغییر مسیر = عدم بازیابی خودکار)

**کاربرد:** شبکه‌های کوچک، مسیرهای ثابت

---

## ۲. مسیریابی داینامیک (Dynamic Routing)

روترها به‌صورت **خودکار** مسیرها را یاد می‌گیرند و به‌روزرسانی می‌کنند.

**پروتکل‌های اصلی:**

| پروتکل | نوع | الگوریتم | مقیاس |
|---|---|---|---|
| RIP | Distance Vector | Bellman-Ford | کوچک |
| OSPF | Link State | Dijkstra | متوسط-بزرگ |
| EGP (BGP) | Path Vector | — | اینترنت |

**مزایا:**
- یادگیری خودکار
- بازیابی خودکار از خرابی
- مقیاس‌پذیری

**معایب:**
- پیچیدگی پیکربندی
- مصرف CPU و حافظه
- ترافیک اضافی

---

## ۳. مقایسه

| ویژگی | استاتیک | داینامیک |
|---|---|---|
| پیکربندی | دستی | خودکار |
| بازیابی از خرابی | خیر | بله |
| مقیاس‌پذیری | ضعیف | قوی |
| مصرف منابع | صفر | متوسط |
| کنترل | کامل | محدودتر |

---

## ❓ سوالات مرور

1. مسیریابی استاتیک چه مزیتی دارد؟
2. RIP از چه الگوریتمی استفاده می‌کند؟
3. چه زمانی مسیریابی داینامیک بهتر است؟
4. BGP چه نقشی در اینترنت دارد؟
