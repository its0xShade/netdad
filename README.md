# 🔌 آموزش شبکه‌های کامپیوتری — Persian Networking Course

> یک دوره آموزشی جامع و مستقل به زبان فارسی، از مقدماتی تا متوسط.

---

## 🎯 هدف پروژه

این پروژه یک دوره آموزشی کامل شبکه‌های کامپیوتری به زبان فارسی است. هدف آن این است که یک دانشجوی مبتدی بتواند از اولین درس شروع کند و بدون نیاز به مطالعه دوره‌های انگلیسی، مفاهیم شبکه را مرحله‌به‌مرحله یاد بگیرد.

**این یک ترجمه از دوره‌های Cisco یا Coursera نیست.** این یک دوره مستقل فارسی است که از دانش و ساختار منابع معتبر برای طراحی بهتر استفاده می‌کند، اما محتوا، مثال‌ها و ساختار آن مستقل و اصیل است.

---

## 👥 مخاطبان

- افرادی که هیچ تجربه‌ای در شبکه ندارند
- دانشجویان رشته‌های کامپیوتر و IT
- علاقه‌مندان به یادگیری شبکه
- افرادی که می‌خواهند مسیر شغلی IT را شروع کنند
- هرکسی که می‌خواهد درک بهتری از نحوه عملکرد اینترنت و شبکه‌ها داشته باشد

## 📚 نحوه مطالعه

1. **ترتیب را رعایت کنید.** هر درس بر درس قبلی استوار است.
2. **ابهام‌ها را برطرف کنید.** اگر مفهومی را متوجه نشدید، درس‌های قبلی را مرور کنید.
3. **تمرین‌ها را انجام دهید.** یادگیری بدون تمرین عملی، ناقص است.
4. **ابزارها را امتحان کنید.** فرمان‌های CLI را روی سیستم خود اجرا کنید.
5. **اصطلاحات را یاد بگیرید.** اصطلاحات انگلیسی برای کار حرفه‌ای ضروری هستند.
