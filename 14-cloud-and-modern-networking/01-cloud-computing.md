# Cloud Computing و شبکه

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- Cloud Computing را توضیح دهد
- مدل‌های IaaS، PaaS، SaaS را مقایسه کند
- تأثیر Cloud بر شبکه را بیان کند

---

## ۱. Cloud چیست؟

ارائه سرویس‌های IT از طریق اینترنت به‌جای سخت‌افزار محلی.

---

## ۲. مدل‌های سرویس

| مدل | توضیح | مثال |
|---|---|---|
| **IaaS** | زیرساخت مجازی | AWS EC2، Azure VM |
| **PaaS** | پلتفرم توسعه | Heroku، Google App Engine |
| **SaaS** | نرم‌افزار آماده | Gmail، Netflix، Office 365 |

---

## ۳. مدل‌های استقرار

| مدل | توضیح |
|---|---|
| **Public Cloud** | سرویس عمومی (AWS، Azure) |
| **Private Cloud** | زیرساخت خصوصی سازمان |
| **Hybrid Cloud** | ترکیب عمومی و خصوصی |

---

## ۴. تأثیر Cloud بر شبکه

- **پهنای باند بیشتر:** نیاز به اتصال سریع‌تر
- **امنیت:** VPN و رمزنگاری ضروری
- **SD-WAN:** مدیریت هوشمند ترافیک Cloud
- **Edge Computing:** پردازش نزدیک‌تر به کاربر
