# VLSM — Variable Length Subnet Mask

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- تفاوت FLSM و VLSM را توضیح دهد
- شبکه‌ای با زیرشبکه‌های مختلف اندازه طراحی کند
- اتلاف آدرس‌ها را با VLSM کاهش دهد

---

> **پیش‌نیاز:** [Subnetting](03-subnetting.md)

---

## ۱. FLSM vs. VLSM

| ویژگی | FLSM | VLSM |
|---|---|---|
| نام | Fixed Length SM | Variable Length SM |
| اندازه Subnet | یکسان | متفاوت |
| انعطاف | کم | زیاد |
| بهره‌وری آدرس | کمتر | بیشتر |

---

## ۲. مشکل FLSM

اگر شبکه `192.168.1.0/24` را به ۴ زیرشبکه /26 تقسیم کنید:

```
زیرشبکه ۱: ۶۲ Host مجاز ← اما فقط ۱۰ دستگاه!
زیرشبکه ۲: ۶۲ Host مجاز ← اما فقط ۵ دستگاه!
زیرشبکه ۳: ۶۲ Host مجاز ← اما فقط ۲۰ دستگاه!
زیرشبکه ۴: ۶۲ Host مجاز ← اما فقط ۳ دستگاه!
```

بسیاری از آدرس‌ها هدر می‌روند!

---

## ۳. راه حل VLSM

با VLSM هر زیرشبکه اندازه مناسب خود را دارد:

```
زیرشبکه ۱ (۶۰ دستگاه): /26 → 192.168.1.0/26     (۶۲ Host)
زیرشبکه ۲ (۲۰ دستگاه): /27 → 192.168.1.64/27    (۳۰ Host)
زیرشبکه ۳ (۱۰ دستگاه): /28 → 192.168.1.96/28    (۱۴ Host)
زیرشبکه ۴ (۲ دستگاه):  /30 → 192.168.1.112/30   (۲ Host)
```

---

## ۴. مراحل VLSM

1. **لیست نیازها:** تعداد Host هر زیرشبکه
2. **مرتب‌سازی:** بزرگترین به کوچکترین
3. **تخصیص:** از بزرگتر شروع کنید
4. **بررسی:** همپوشانی وجود نداشته باشد

---

## ❓ سوالات مرور

1. تفاوت FLSM و VLSM چیست؟
2. چرا VLSM بهره‌وری آدرس را بالا می‌برد؟
3. چرا در VLSM باید از بزرگتر شروع کرد؟
