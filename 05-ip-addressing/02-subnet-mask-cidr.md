# Subnet Mask و CIDR

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- Subnet Mask را به‌صورت باینری توضیح دهد
- نمایش CIDR را به Subnet Mask تبدیل کند
- بخش Network و Host را با استفاده از Subnet Mask استخراج کند

---

> **پیش‌نیاز:** [آدرس‌دهی IPv4](01-ipv4-addressing.md)

---

## ۱. Subnet Mask چیست؟

Subnet Mask یک عدد ۳۲ بیتی است که مشخص می‌کند کدام بیت‌های آدرس IP مربوط به **شبکه** و کدام به **میزبان** هستند.

---

## ۲. نمایش باینری

```
آدرس IP:      192.168.1.100
              11000000.10101000.00000001.01100100

Subnet Mask:  255.255.255.0
              11111111.11111111.11111111.00000000
              ←─── ۲۴ بیت Network ───→←─ ۸ بیت Host ─→
```

**عمل AND بین IP و Mask:**
```
IP:   11000000.10101000.00000001.01100100
Mask: 11111111.11111111.11111111.00000000
AND:  11000000.10101000.00000001.00000000
=     192.168.1.0  ← آدرس شبکه
```

---

## ۳. نمایش CIDR

CIDR تعداد بیت‌های Network را با `/N` نشان می‌دهد:

| CIDR | Subnet Mask | بیت Network | تعداد Host |
|---|---|---|---|
| /8 | 255.0.0.0 | ۸ | ۱۶,۷۷۷,۲۱۴ |
| /16 | 255.255.0.0 | ۱۶ | ۶۵,۵۳۴ |
| /24 | 255.255.255.0 | ۲۴ | ۲۵۴ |
| /25 | 255.255.255.128 | ۲۵ | ۱۲۶ |
| /26 | 255.255.255.192 | ۲۶ | ۶۲ |
| /27 | 255.255.255.224 | ۲۷ | ۳۰ |
| /28 | 255.255.255.240 | ۲۸ | ۱۴ |
| /30 | 255.255.255.252 | ۳۰ | ۲ |
| /31 | 255.255.255.254 | ۳۱ | ۲ (Point-to-Point) |
| /32 | 255.255.255.255 | ۳۲ | ۱ (Host واحد) |

**فرمول:** تعداد Host = 2^(32-N) - 2

---

## ۴. آدرس‌های رزرو شده

در هر زیرشبکه، دو آدرس قابل استفاده نیستند:

| آدرس | نحوه محاسبه | توضیح |
|---|---|---|
| آدرس شبکه | همه Host bits = 0 | شناسه زیرشبکه |
| آدرس Broadcast | همه Host bits = 1 | ارسال به همه |

---

## ۵. مثال عملی

آدرس `172.16.5.130/26`:

```
Mask: 255.255.255.192
بیت Network: 26
بیت Host: 6

172.16.5.130 = 10101100.00010000.00000101.10000010
255.255.255.192 = 11111111.11111111.11111111.11000000

Network bits: 10101100.00010000.00000101.10
Host bits: 000010

آدرس شبکه:     172.16.5.128
آدرس Broadcast: 172.16.5.191
دامنه معتبر:    172.16.5.129 تا 172.16.5.190
تعداد Host:     62
```

## ❓ سوالات مرور

1. /27 چند Host دارد؟
2. Subnet Mask چه چیزی را مشخص می‌کند؟
3. آدرس 192.168.1.1/24 — آدرس شبکه چقدر است؟
4. تفاوت آدرس Network و Broadcast چیست؟
