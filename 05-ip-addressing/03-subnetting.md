# Subnetting — مرحله به مرحله

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- یک شبکه را به چند زیرشبکه تقسیم کند
- برای هر زیرشبکه، محدوده آدرس‌ها را محاسبه کند
- Subnetting ساده را بدون ماشین‌حساب انجام دهد

---

> **پیش‌نیاز:** [Subnet Mask و CIDR](02-subnet-mask-cidr.md)

---

## ۱. چرا Subnetting؟

Subnetting تقسیم یک شبکه بزرگ به چند شبکه کوچکتر است. مزایا:
- **کاهش Broadcast**
- **بهبود امنیت** (جداسازی بخش‌ها)
- **مدیریت بهتر آدرس‌ها**

---

## ۲. مراحل Subnetting

### مرحله ۱: تعداد زیرشبکه‌های مورد نیاز را مشخص کنید

اگر به ۴ زیرشبکه نیاز دارید: 2^2 = 4 → **۲ بیت** از Host قرض بگیرید.

### مرحله ۲: Subnet Mask جدید را محاسبه کنید

Mask اولیه: /24 → جدید: /24 + 2 = **/26**

### مرحله ۳: اندازه هر زیرشبکه را محاسبه کنید

بیت‌های Host: 32 - 26 = 6 → 2^6 = 64 آدرس → 62 Host معتبر

### مرحله ۴: محدوده هر زیرشبکه را بنویسید

```
زیرشبکه ۱: 192.168.1.0/26    (0-63)
زیرشبکه ۲: 192.168.1.64/26   (64-127)
زیرشبکه ۳: 192.168.1.128/26  (128-191)
زیرشبکه ۴: 192.168.1.192/26  (192-255)
```

---

## ۳. مثال کامل: تقسیم 192.168.10.0/24 به ۸ زیرشبکه

**مرحله ۱:** ۸ زیرشبکه → 2^3 = 8 → ۳ بیت قرض
**مرحله ۲:** /24 + 3 = /27
**مرحله ۳:** 32-27 = 5 بیت Host → 2^5 = 32 → 30 Host
**مرحله ۴:** فاصله: 256/8 = 32

```
زیرشبکه ۱: 192.168.10.0/27    (0-31)     Hosts: 1-30
زیرشبکه ۲: 192.168.10.32/27   (32-63)    Hosts: 33-62
زیرشبکه ۳: 192.168.10.64/27   (64-95)    Hosts: 65-94
زیرشبکه ۴: 192.168.10.96/27   (96-127)   Hosts: 97-126
زیرشبکه ۵: 192.168.10.128/27  (128-159)  Hosts: 129-158
زیرشبکه ۶: 192.168.10.160/27  (160-191)  Hosts: 161-190
زیرشبکه ۷: 192.168.10.192/27  (192-223)  Hosts: 193-222
زیرشبکه ۸: 192.168.10.224/27  (224-255)  Hosts: 225-254
```
