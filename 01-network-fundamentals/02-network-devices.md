# دستگاه‌های شبکه — Network Devices

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- تفاوت Hub، Switch و Router را توضیح دهد
- نقش مودم، Access Point و Firewall را در شبکه بیان کند
- تشخیص دهد هر دستگاه در کدام لایه مدل OSI کار می‌کند
- یک شبکه خانگی ساده را از نظر دستگاه‌ها توصیف کند

---

> **پیش‌نیاز:** [درس ۰۱ — شبکه کامپیوتری چیست؟](01-what-is-a-network.md)

## ۱. مقدمه

در درس قبلی با مفهوم شبکه آشنا شدید. دانستیم شبکه مجموعه‌ای از دستگاه‌های متصل است. اما این دستگاه‌ها چه هستند و هر کدام چه نقشی دارند؟

فرض کنید در خانه یک لپ‌تاپ، یک گوشی و یک تلویزیون هوشمند دارید. همه اینها باید به اینترنت وصل شوند. چه دستگاه‌هایی این کار را ممکن می‌کنند؟

---

## ۲. دستگاه‌های پایانی (End Devices)

این دستگاه‌ها **منبع یا مقصد نهایی داده** هستند:

- **کامپیوتر و لپ‌تاپ** — ارسال و دریافت اطلاعات
- **گوشی و تبلت** — اتصال به اینترنت و اپلیکیشن‌ها
- **سرور** — میزبانی وب‌سایت، ایمیل، فایل و سرویس‌ها
- **چاپگر شبکه** — دریافت درخواست‌های چاپ از چند دستگاه
- **دوربین IP** — ارسال تصاویر از طریق شبکه
- **تلویزیون هوشمند** — دریافت محتوای استریم

---

## ۳. دستگاه‌های میانی (Intermediary Devices)

این دستگاه‌ها **بین دستگاه‌های پایانی** قرار می‌گیرند و مسیر انتقال داده را مدیریت می‌کنند.

### ۳.۱ Hub (هاپ)

**هاپ** ساده‌ترین دستگاه میانی است. وقتی داده‌ای از یک پورت وارد می‌شود، هاپ آن را به **تمام** پورت‌های دیگر ارسال می‌کند — بدون اینکه بداند مقصد کجاست.

```text
        ┌─── کامپیوتر A
        │
   ┌────┤
   │Hub │
   └────┤
        │
        ├─── کامپیوتر B  ← داده برای A هم به B می‌رسد
        │
        └─── کامپیوتر C  ← و به C هم می‌رسد
```

**مشکل هاپ:**
- تمام ترافیک به همه ارسال می‌شود → **اتلاف پهنای باند**
- تداخل داده‌ها (Collision) زیاد است
- امنیت ضعیف — همه می‌توانند ترافیک یکدیگر را ببینند

> **نتیجه:** هاپ‌ها امروزه منسوخ شده‌اند و تقریباً استفاده نمی‌شوند.

### ۳.۲ Switch (سوئیچ)

**سوئیچ** هوشمندتر از هاپ است. سوئیچ یاد می‌گیرد کدام دستگاه به کدام پورت متصل است و داده را **فقط** به پورت مقصد ارسال می‌کند.

```text
        ┌─── کامپیوتر A
        │
   ┌────┤
   │Switch│   ← داده فقط به پورت مقصد می‌رسد
   └────┤
        │
        ├─── کامپیوتر B
        │
        └─── کامپیوتر C
```

**مزایای سوئیچ نسبت به هاپ:**

| ویژگی | Hub | Switch |
|---|---|---|
| ارسال داده | به همه پورت‌ها | فقط به پورت مقصد |
| Collision Domain | مشترک بین همه | جدا برای هر پورت |
| امنیت | ضعیف | بهتر |
| سرعت واقعی | کمتر (تداخل) | بیشتر |

**سوئیچ در لایه دوم OSI (Data Link Layer) کار می‌کند** و از آدرس MAC برای شناسایی دستگاه‌ها استفاده می‌کند.

### ۳.۳ Router (روتر)

**روتر** دستگاهی است که **بین شبکه‌های مختلف** مسیریابی می‌کند. اگر سوئیچ دستگاه‌ها را در **یک** شبکه محلی به هم وصل می‌کند، روتر شبکه شما را به **شبکه‌های دیگر** (مثل اینترنت) متصل می‌کند.

```text
   شبکه خانه شما              اینترنت
   ┌─────────┐              ┌─────────┐
   │ لپ‌تاپ  │              │ سرور   │
   │ گوشی    │── Router ───│ Google  │
   │ تلویزیون│              │         │
   └─────────┘              └─────────┘
```

**روتر در لایه سوم OSI (Network Layer) کار می‌کند** و از آدرس IP برای مسیریابی بسته‌ها استفاده می‌کند.

**روتر چه کاری انجام می‌دهد:**
- دریافت بسته از یک شبکه
- بررسی آدرس مقصد
- انتخاب بهترین مسیر
- ارسال بسته به شبکه بعدی

### ۳.۴ مودم (Modem)

**مودم** سیگنال دیجیتال کامپیوتر شما را به سیگنالی تبدیل می‌کند که روی خط تلفن، کابل یا فیبر قابل ارسال باشد و بالعکس.

نام Modem از ترکیب **Mo**dulator و **Dem**odulator گرفته شده است.

```text
کامپیوتر ←→ [مودم] ←→ خط تلفن/کابل ←→ ISP ←→ اینترنت
```

### ۳.۵ Access Point (AP)

**نقطه دسترسی بی‌سیم** (Wireless Access Point) دستگاهی است که اتصال Wi-Fi را فراهم می‌کند. AP سیگنال بی‌سیم را به شبکه سیمی تبدیل می‌کند.

```text
  گوشی ──── Wi-Fi ────→ [AP] ──── کابل ────→ [سوئیچ] ────→ شبکه
```

> **نکته:** در بسیاری از خانه‌ها، روتر، سوئیچ، مودم و AP همه در یک دستگاه ترکیب شده‌اند که به آن **روتر خانگی** یا **Gateway** می‌گویند.

### ۳.۶ Firewall (دیوار آتش)

**فایروال** دستگاه یا نرم‌افزاری است که ترافیک ورودی و خروجی شبکه را بر اساس **قوانین امنیتی** بررسی و فیلتر می‌کند.

```text
اینترنت ←→ [فایروال] ←→ شبکه داخلی
                │
         ┌──────────────┐
         │ قوانین:      │
         │ ✅ اجازه HTTPS│
         │ ✅ اجازه DNS │
         │ ❌ مسدود Telnet│
         └──────────────┘
```

## ۴. مقایسه دستگاه‌ها بر اساس لایه OSI

| دستگاه | لایه OSI | آدرس مورد استفاده | عملکرد اصلی |
|---|---|---|---|
| Hub | لایه ۱ (Physical) | ندارد | ارسال به همه |
| Switch | لایه ۲ (Data Link) | MAC Address | ارسال به مقصد مشخص |
| Router | لایه ۳ (Network) | IP Address | مسیریابی بین شبکه‌ها |
| Firewall | لایه ۳-۷ | IP, Port | فیلتر ترافیک |

---

## ۵. مثال واقعی: شبکه خانگی

بیایید ببینیم در یک خانه معمولی چه دستگاه‌هایی نقش دارند:

```text
اینترنت
   │
   ├── [مودم] ←── اتصال به خط ISP
   │      │
   │   [روتر خانگی] ←── روتینگ + فایروال + Wi-Fi
   │      │
   │   [سوئیچ داخلی]
   │      │
   │   ┌──┴──────────────────────┐
   │   │            │            │
   │ [لپ‌تاپ]  [تلویزیون]  [پرینتر]
   │  (سیمی)   (Wi-Fi)    (Wi-Fi)
   │
   └─── [گوشی] ←── Wi-Fi ←── [AP یا همان روتر]
```

---

## ۶. خلاصه

- **دستگاه‌های پایانی** (End Devices) منبع یا مقصد داده هستند.
- **Hub** ساده ولی منسوخ است — داده را به همه ارسال می‌کند.
- **Switch** هوشمندتر است — داده را فقط به مقصد می‌فرستد (لایه ۲).
- **Router** بین شبکه‌ها مسیریابی می‌کند (لایه ۳).
- **مودم** سیگنال دیجیتال را برای ارسال روی خط تبدیل می‌کند.
- **Access Point** اتصال Wi-Fi را فراهم می‌کند.
- **فایروال** ترافیک را فیلتر و امنیت را تأمین می‌کند.
- در خانه‌ها، معمولاً چند نقش در یک دستگاه ترکیب شده‌اند.

---

## ⚠️ خطاهای رایج

1. **ادغام Switch و Router:** Switch دستگاه‌ها را در یک شبکه محلی متصل می‌کند. Router شبکه محلی را به شبکه‌های دیگر (اینترنت) وصل می‌کند.

2. **فکر کردن Hub جایگزین Switch است:** Hub امروزه تقریباً استفاده نمی‌شود. اگر دستگاهی چند پورت شبکه دارد، احتمالاً Switch است.

3. **فکر کردن مودم همان روتر است:** مودم فقط تبدیل سیگنال انجام می‌دهد. روتر تصمیم می‌گیرد بسته به کجا برود.

---

## ❓ سوالات مرور

1. تفاوت Hub و Switch را توضیح دهید.
2. چرا Hub منسوخ شده است؟
3. Router در کدام لایه مدل OSI کار می‌کند؟
4. در یک شبکه خانگی، چه دستگاه‌هایی نقش دارند؟
5. اگر می‌خواهید ۳ کامپیوتر را به هم وصل کنید و همه به اینترنت دسترسی داشته باشند، به چه دستگاه‌هایی نیاز دارید؟
