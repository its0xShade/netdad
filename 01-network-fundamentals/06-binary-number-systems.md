# سیستم‌های عددی — دودویی و هگزادسیمال

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- سیستم دودویی (Binary) و هگزادسیمال (Hexadecimal) را درک کند
- بین اعداد دهدهی، دودویی و هگزادسیمال تبدیل انجام دهد
- مفهوم Bit و Byte را توضیح دهد
- درک کند چرا کامپیوترها از دودویی استفاده می‌کنند

---

> **پیش‌نیاز:** [درس ۰۱ — شبکه کامپیوتری چیست؟](01-what-is-a-network.md)

---

## ۱. چرا دودویی؟

کامپیوترها فقط دو حالت را می‌فهمند: **روشن** و **خاموش** — یعنی **۱** و **۰**. به همین دلیل زبان اصلی کامپیوتر **سیستم دودویی (Binary)** است.

هر عدد، حرف یا تصویری که می‌بینید، در نهایت به مجموعه‌ای از ۰ و ۱ تبدیل می‌شود.

---

## ۲. سیستم دهدهی (Decimal)

سیستمی که روزمره استفاده می‌کنیم. پایه **۱۰** است.

```text
255 = 2×10² + 5×10¹ + 5×10⁰
```

ارزش هر رقم = رقم × ۱۰^(مکان)

---

## ۳. سیستم دودویی (Binary)

پایه **۲** است. فقط دو رقم: ۰ و ۱.

ارزش هر بیت = ۲^(مکان)

```text
بیت:     7    6    5    4    3    2    1    0
ارزش:  128   64   32   16    8    4    2    1
```

### مثال: تبدیل دودویی به دهدهی

```
10110100 = 128 + 0 + 32 + 16 + 0 + 4 + 0 + 0 = 180
```

### مثال: تبدیل دهدهی به دودویی

عدد **۱۷۲**:

```
172 ≥ 128 → بیت 7 = 1 → باقیمانده: 44
44  ≥ 64  → بیت 6 = 0
44  ≥ 32  → بیت 5 = 1 → باقیمانده: 12
12  ≥ 16  → بیت 4 = 0
12  ≥ 8   → بیت 3 = 1 → باقیمانده: 4
4   ≥ 4   → بیت 2 = 1 → باقیمانده: 0
نتیجه: 10101100
```

---

## ۴. سیستم هگزادسیمال (Hexadecimal)

پایه **۱۶** است. ارقام: ۰-۹ و A-F.

```text
A = 10, B = 11, C = 12, D = 13, E = 14, F = 15
```

هر رقم هگزادسیمال = ۴ بیت (Nibble)

**چرا مهم است؟** هگزادسیمال روش فشرده‌ای برای نمایش اعداد بزرگ دودویی است.

### مثال‌ها

| دهدهی | دودویی | هگزادسیمال |
|---|---|---|
| ۰ | 0000 | 0 |
| ۱۰ | 1010 | A |
| ۱۵ | 1111 | F |
| ۱۲۸ | 10000000 | 80 |
| ۲۵۵ | 11111111 | FF |
| ۱۷۲ | 10101100 | AC |

### کاربرد در شبکه

- **آدرس MAC:** `AC:DE:48:23:45:67` (۶ بایت = ۱۲ رقم Hex)
- **آدرس IPv6:** `2001:0db8:85a3::8a2e:0370:7334`
- **رنگ در HTML:** `#FF5733`

---

## ۵. Bit و Byte

| واحد | اندازه | توضیح |
|---|---|---|
| Bit | ۱ | کوچک‌ترین واحد: ۰ یا ۱ |
| Nibble | ۴ Bit | یک رقم هگزادسیمال |
| Byte | ۸ Bit | یک حرف ASCII |

**تفاوت حرف big-B و small-b:**
- **B** = Byte (بایت)
- **b** = bit (بیت)
- 1 Byte = 8 bits
- 100 B/s ≠ 100 b/s (تفاوت ۸ برابر!)

---

## ۶. عملیات بیتی اصلی

| عمل | نماد | مثال |
|---|---|---|
| AND | & | 1010 & 1100 = 1000 |
| OR | \| | 1010 \| 1100 = 1110 |
| XOR | ^ | 1010 ^ 1100 = 0110 |
| NOT | ~ | ~1010 = 0101 |
| Shift | << >> | 0001 << 3 = 1000 |

**کاربرد در شبکه:** عمل AND بین آدرس IP و Subnet Mask بخش Network را استخراج می‌کند.

---

## ۷. تمرین عملی

تبدیل آدرس IP `192.168.1.1` به دودویی:

```
192 = 11000000
168 = 10101000
1   = 00000001
1   = 00000001

کل: 11000000.10101000.00000001.00000001
```
