# پهنای باند، تأخیر و ازدحام — Bandwidth, Latency, Congestion

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- پهنای باند و توان عملیاتی (Throughput) را از هم تمییز دهد
- انواع تأخیر (Latency) را نام ببرد
- ازدحام شبکه (Congestion) را توضیح دهد
- عوامل مؤثر بر کیفیت اتصال شبکه را بشناسد

## ۱. پهنای باند (Bandwidth)

**پهنای باند** حداکثر مقدار داده‌ای است که یک لینک شبکه می‌تواند در واحد زمان منتقل کند.

**واحدها:**
- bps (bit per second)
- Kbps = ۱,۰۰۰ bps
- Mbps = ۱,۰۰۰,۰۰۰ bps
- Gbps = ۱,۰۰۰,۰۰۰,۰۰۰ bps

**مثال:** اگر پهنای باند اینترنت شما ۱۰۰ Mbps است، یعنی حداکثر ۱۰۰ میلیون بیت در ثانیه می‌توانید دریافت کنید.

> **نکته:** پهنای باند مثل ظرفیت یک بزرگراه است — هرچه بزرگتر، ترافیک بیشتری عبور می‌کند.

---

## ۲. توان عملیاتی (Throughput)

**Throughput** مقدار واقعی داده‌ای است که در عمل منتقل می‌شود. معمولاً کمتر از پهنای باند است.

```text
پهنای باند (ظرفیت نظری):  100 Mbps
Throughput (واقعی):         85 Mbps
                              ↑
                    دلیل: سربار پروتکل، خطاها، ازدحام
```

**علل کاهش Throughput:**
- سربار Headerهای پروتکل (TCP/IP)
- خطاها و باز ارسال بسته‌ها
- ازدحام شبکه
- محدودیت سرور مقصد

---

## ۳. تأخیر (Latency)

**تأخیر** زمانی است که طول می‌کشد یک بسته از مبدأ به مقصد برسد. با **milisecond (ms)** اندازه‌گیری می‌شود.

### انواع تأخیر

| نوع | توضیح | مثال |
|---|---|---|
| **Propagation Delay** | زمان حرکت سیگنال روی رسانه | نور در فیبر: ~۵ μs/km |
| **Transmission Delay** | زمان ارسال تمام بیت‌های بسته روی لینک | بسته ۱۵۰۰ بایت روی لینک ۱۰۰ Mbps |
| **Processing Delay** | زمان پردازش بسته توسط روتر | بررسی Header، تصمیم‌گیری مسیر |
| **Queuing Delay** | زمان انتظار بسته در صف روتر | وقتی ترافیک زیاد است |

** Latency کل = Propagation + Transmission + Processing + Queuing**

### مثال واقعی

```text
ping google.com

Packets: Sent = 4, Received = 4, Lost = 0
Average RTT = 12ms
```

**RTT (Round-Trip Time)** = تأخیر رفت و برگشت

---

## ۴. ازدحام (Congestion)

وقتی ترافیک شبکه از ظرفیت آن بیشتر شود، **ازدحام** ایجاد می‌شود.

```text
وضعیت عادی:     [Router] ← ۵۰ بسته/ثانیه ← ظرفیت: ۱۰۰
وضعیت ازدحام:   [Router] ← ۱۵۰ بسته/ثانیه ← ظرفیت: ۱۰۰
                                  ↓
                          بسته‌ها دور ریخته می‌شوند!
```

**نتایج ازدحام:**
- افزایش Latency
- از دست رفتن بسته‌ها (Packet Loss)
- کاهش Throughput
- کاهش کیفیت تماس تصویری/بازی آنلاین

**مثال واقعی:** وقتی همه اعضای خانواده همزمان ویدیو تماشا می‌کنند، سرعت اینترنت کم می‌شود — این ازدحام است.

---

## ۵. کیفیت سرویس (QoS)

**QoS** مکانیزمی برای **اولویت‌بندی ترافیک** شبکه است.

مثال: وقتی همزمان دارید فایل دانلود می‌کنید و تماس تصویری دارید، QoS ترافیک تماس تصویری را اولویت می‌دهد تا قطع نشود.

**اولویت‌بندی معمول:**
1. تماس صوتی/تصویری (بالاترین اولویت)
2. اپلیکیشن‌های Real-time (بازی)
3. ایمیل و مرور وب
4. دانلود فایل (پایین‌ترین اولویت)

---

## ۶. مقایسه پهنای باند و Latency

| ویژگی | پهنای باند | Latency |
|---|---|---|
| معنی | چقدر داده؟ | چقدر سریع؟ |
| واحد | Mbps/Gbps | ms |
| مثال | ۱۰۰ Mbps اینترنت | ۱۵ms تأخیر |
| اهمیت برای | دانلود حجیم | بازی آنلاین، VoIP |

> **مثال ساده:** پهنای باند مثل عرض جاده و Latency مثل فاصله مبدأ تا مقصد است.

## ❓ سوالات مرور

1. تفاوت پهنای باند و Throughput را توضیح دهید.
2. چهار نوع تأخیر را نام ببرید.
3. ازدحام شبکه چه اثری بر کیفیت تماس تصویری دارد؟
4. QoS چیست و چه کاری انجام می‌دهد؟
5. اگر Latency بازی آنلاین ۵۰۰ms باشد، مشکل چیست؟
