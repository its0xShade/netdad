# ساختار آدرس IPv6

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- آدرس IPv6 را بخواند و بنویسد
- قوانین فشرده‌سازی را بداند
- انواع آدرس IPv6 را نام ببرد

---

## ۱. فرمت آدرس IPv6

آدرس IPv6 شامل **۸ بخش ۱۶ بیتی** است که با دونقطه (:) جدا می‌شوند:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

هر بخش = ۴ رقم Hexadecimal

---

## ۲. قوانین فشرده‌سازی

**قانون ۱:** صفرهای ابتدایی هر بخش حذف می‌شوند:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
→ 2001:db8:85a3:0:0:8a2e:370:7334
```

**قانون ۲:** یک بلوک صفرهای متوالی با `::` جایگزین می‌شود (فقط یک‌بار):

```
2001:db8:85a3::8a2e:370:7334
```

> قانون :: فقط **یک‌بار** در آدرس استفاده می‌شود.

---

## ۳. انواع آدرس IPv6

| نوع | پیشوند | توضیح |
|---|---|---|
| **Unicast Global** | 2000::/3 | آدرس عمومی قابل مسیریابی |
| **Unicast Link-Local** | FE80::/10 | فقط در لینک محلی |
| **Unicast Loopback** | ::1 | تست خود سیستم |
| **Multicast** | FF00::/8 | ارسال به گروه |
| **Unspecified** | :: | آدرس نامشخص |

---

## ۴. آدرس‌های خصوصی IPv6

| بازه | توضیح |
|---|---|
| FC00::/7 | Unique Local Address (مشابه 10.0.0.0) |
| FE80::/10 | Link-Local (مشابه APIPA) |
| ::1 | Loopback (مشابه 127.0.0.1) |

---

## ❓ سوالات مرور

1. آدرس IPv6 چند بخش دارد؟
2. قانون :: چیست؟
3. FE80::/10 چیست؟
4. ::1 معادل کدام آدرس IPv4 است؟
