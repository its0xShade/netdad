# NAT — Network Address Translation

## 🎯 اهداف یادگیری

در پایان این درس، دانشجو می‌تواند:

- NAT را به‌عنوان مترجم آدرس توضیح دهد
- انواع NAT را نام ببرد
- درک کند NAT چگونه کمبود IPv4 را کاهش می‌دهد

---

## ۱. NAT چیست؟

**Network Address Translation** تبدیل آدرس‌های **خصوصی** به **عمومی** و بالعکس است.

بدون NAT، هر دستگاه خانگی به یک آدرس Public نیاز داشت — اما آدرس IPv4 محدود است!

---

## ۲. نحوه عملکرد

```
گوشی (192.168.1.105) → [روتر با NAT] → اینترنت (85.214.132.117)
                                            ↓
                                    سرور Google
                                    "درخواست از 85.214.132.117"
```

روتر جدولی نگه می‌دارد که نشان دهد کدام درخواست خصوصی مربوط به کدام درخواست عمومی است.

---

## ۳. انواع NAT

### Static NAT
یک به یک: هر آدرس خصوصی به یک آدرس عمومی ثابت تبدیل می‌شود.

### Dynamic NAT
آدرس‌های عمومی از یک استخر (Pool) به ترتیب اختصاص داده می‌شوند.

### PAT (Port Address Translation) — رایج‌ترین
چندین آدرس خصوصی از طریق **یک آدرس عمومی** با **شماره پورت متفاوت** متصل می‌شوند.

```
192.168.1.105:5000 → 85.214.132.117:40001
192.168.1.106:5000 → 85.214.132.117:40002
192.168.1.107:5000 → 85.214.132.117:40003
```

---

## ۴. مزایا و معایب

| مزیت | عیب |
|---|---|
| صرفه‌جویی در آدرس IPv4 | پیچیدگی پیکربندی |
| امنیت (آدرس خصوصی مخفی) | مشکل با برخی پروتکل‌ها (P2P) |
| انعطاف‌پذیری | Latency اضافی |
